# Finnplay Test Task

Full-stack React and Node.js application for filtering games by name, provider, and group.

## Project Structure

- `client` - React application
- `server` - Node.js API
- `shared` - shared TypeScript types and contracts
- `data.json` - initial in-memory catalog data
